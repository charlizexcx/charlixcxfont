# Charli XCX Handwriting Font 💚

An unofficial fan-made font created from Charli xcx's actual handwriting, digitised for fans to download and install.

## Download

**[Download the latest version](../../releases/latest)**

Download the font file from the Assets section of the latest release.

## Installation

### macOS
1. Download the `.ttf` or `.otf` font file.
2. Double-click the downloaded file.
3. Click **Install Font** to add it to Font Book.

### Windows
1. Download the `.ttf` or `.otf` font file.
2. Right-click the downloaded file.
3. Select **Install**.
